The 4515 is a 4510 with a keystroke recorder. Identical three-level stack, identical register classes, identical Appendix C error limits. What it adds is 100 steps of learn-mode programming: no branching, no labels, no subroutines.

LOAD. start wipes program storage and begins the first program. Every key after that is recorded and executed, so you debug with live values as you type. halt records a pause for a variable — digits keyed straight after one are not stored. Digits keyed without a preceding halt become constants. skip ends one program and starts the next. del erases the last step.

RUN. start runs to the next halt, or resumes from one. skip abandons the rest of the current program and moves to the next; n−1 touches reach the nth. STEP executes one step per touch of start.

An F-shifted key counts as one step, as in the manual's listings. Over 100 steps, or deleting a skip, shows all decimal points — the same indication the display gives after 35 seconds idle.

Eight digits, no guard digits. Registers are truncated to eight positions after every operation, not just at display — the manual's sphere program proves it. Every numeric result printed in the manual reproduces exactly, with one exception: yx goes through the ROM's own log and antilog, so 1.08510 reads 2.26098 on real hardware and 2.2609834 here.

Keyboard: digits, . + - * /, Enter, Backspace (C), f, c (CHS), x, s (start), h (halt), k (skip), d (del), Esc.
